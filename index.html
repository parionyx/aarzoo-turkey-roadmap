TBBS Application Steps
  1. Open official portal: turkiyeburslari.gov.tr → "Apply" (TBBS system)
  2. Create account + enter identity/education details accurately
  3. Upload all docs (passport, diploma, transcript, MOI, photo)
  4. Search programs with "English" filter → pick CS/AI MSc (up to 12)
  5. Write motivation letter + study plan (consistent with CV/LORs)
  6. Attach 2 recommendation letters
  7. Review → submit before 20 Feb → save confirmation email
  8. Prep interview: know your exact files + program details
